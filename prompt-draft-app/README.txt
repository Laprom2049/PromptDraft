Prompt 文稿 0.1.0 — Windows 64 位预览版
=======================================

这是一款用于编写和整理提示词的本地编辑器。安装包包含程序启动器、完整离线页面及本说明。
程序使用电脑上已经安装的 Microsoft Edge 打开独立应用窗口；安装包不包含浏览器内核。

一、系统要求与安装

• 目标系统：Windows 10 / Windows 11，x64（64 位）。
• 需要已安装较新的 Microsoft Edge。
• 双击 PromptDraft-Setup-0.1.0-x64.exe，按提示安装，然后使用桌面或开始菜单的快捷方式启动。
• 安装面向当前用户，不需要安装 Node.js、Python 或开发工具。
• 编辑功能无需联网，不需要账号或模型 API Key。

二、主要功能

• 编辑标题、正文、段落用途及作者备注，添加或删除段落。
• 使用 {{变量名}} 创建变量，例如 {{project}}、{{项目名称}}。
• 在侧栏填写变量，并查看变量替换后的发送预览。
• 开启或关闭固定的“结果报告”引用片段。
• 检查未填写变量、空变量名和未闭合的变量占位符。
• 打开项目文件，导入 TXT/Markdown，导出项目和发送文本，复制发送内容。
• 尝试保存本机自动恢复副本，并提示保存失败或其他窗口的修改冲突。

变量值按普通数据插入一次，不会递归解释其中的 {{另一变量}}。
如需在正文中保留字面的 {{，可写成 \{{。
作者备注会随完整项目导出，但不会进入发送预览、复制内容或导出的发送文本。

三、保存与备份

完整项目文件使用 .prompt.json 扩展名，包含正文、变量值、备注和片段状态。
请使用“保存项目”或相应导出按钮下载完整项目，以便备份、换电脑或继续编辑。
TXT/Markdown 导出只包含展开后的发送内容，不包含完整的编辑元信息。

导出使用 Edge 的下载流程，位置取决于浏览器设置，通常可在系统“下载”文件夹找到。
页面显示“下载已发起”仅表示已请求下载，请确认文件确实出现在你的电脑中。

程序会尝试使用本机浏览器存储更新自动恢复副本。它不是项目文件备份。
file: 页面存储行为受浏览器版本、设置和企业策略影响；页面会在失败时提示导出项目。
普通环境下，启动器指定的数据目录为：
    %LOCALAPPDATA%\PromptDraft\BrowserData
企业管理策略可能覆盖浏览器数据目录设置。
不要在尚未备份文稿时清理该目录或浏览器数据。

四、快捷键

Ctrl+S：导出完整项目文件。
Ctrl+O：打开项目文件或导入文本。
Ctrl+Z / Ctrl+Y：使用文本编辑控件的撤销/重做功能。

五、能力范围

本版本用于写作、整理和导出提示词，尚未连接模型、Shell 或 Agent 执行器。
“约束”“验收”等标签用于组织文稿；不会自动对外部 Agent 施加权限或执行限制。
页面内没有外部资源和联网请求；Edge 自身的更新等后台行为由浏览器和系统管理。

六、卸载

可通过 Windows 的已安装应用列表或安装目录中的卸载程序卸载。
卸载移除程序文件和快捷方式，默认保留 BrowserData 以及你已导出的项目文件。
卸载前建议导出需要保留的完整项目。若只想更新，请安装到同一路径，以保持恢复路径稳定。

七、预览版与验证范围

此安装包未进行数字签名。
已检查核心内容逻辑、中文项目序列化、变量替换、备注排除和安装包 PE 结构。
当前制作环境不是 Windows，尚未进行 Windows 真机安装、Edge 窗口、输入法和卸载的端到端验证。
请先使用一份测试文稿，确认保存、重新打开和导出正常后再保存重要内容。
若系统或组织策略阻止运行，请遵循系统策略；本说明不要求关闭系统防护。
