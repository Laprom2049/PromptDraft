使用 Prompt 文稿

      
直接写正文，按需为段落标记用途。{{项目名}} 这样的变量会在右侧出现输入框。

      
保存与备份

      
编辑内容会尝试自动保存在本机浏览器数据中。请留意顶部的保存状态。清理浏览器数据、修改安装路径或更换电脑可能影响自动恢复。

      
点击“保存项目”或按 Ctrl+S 下载 .prompt.json 文件，保存所有正文、变量与作者备注。文件通常进入系统下载目录；浏览器可能询问保存位置。用“打开”可继续编辑。

      
发送内容

      
“发送预览”会替换变量、展开片段，并排除作者备注。支持复制、导出 TXT 或 Markdown。“段落用途”仅用于组织文字，尚未接入模型、检查器或 Agent 执行器。

      
常用操作

      
Ctrl+O 打开项目或文本；Ctrl+S 保存项目；Ctrl+Z 撤销当前文本框中的文字编辑。删除段落需要确认，打开或新建文稿前会尝试保存历史快照。

      
本页不发送网络请求。程序使用系统 Edge 独立窗口；浏览器自身的更新和系统服务由其设置管理。
